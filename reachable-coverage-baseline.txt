# 可达命令名覆盖率基线（棘轮：分母不缩水 + 缺口恒 0）
#
# 口径（写死；改口径 = 改门，必须同笔说明）：
#   可达 = 从初始状态出发，经 `valid` 表（= [[transitions]] 派生）合法边可达的命令名；
#          不是"语法上存在的命令名"，也不是"任意状态有出边"。
#   覆盖 = 该命令名在**实际执行过**的用例里出现过。
#          分子来自 qcs `RunReport.command_distribution`（执行记录），
#          **不是** `reachable_witness_paths()` 的路径声明——声明与执行脱钩就是假绿。
#   分母 = 可达命令名集合；不可达项**不进分母**，另由结构钉子钉住（见下方"不进分母"节）。
#
# 判据（两道，红了就是红了；比率只作展示——缺口清零时恒 1000‰）：
#   ① 缺口清零门：缺口 = 分母 − 分子，必须为空（测试内断言，缺口逐名打印）；
#   ② 分母棘轮：`reachable_total` 只许不缩水（`unreachable_pinned` 只许不增）——
#      低于/超过本文件即红；高于本文件打 ::notice:: 提示同笔推高。
#   守恒：分母 + 不可达 = 全部命令名（测试内断言）。
