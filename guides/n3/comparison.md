## 2. 术语位置对照

| 术语 | 主语 | 谓语 | 宾语 | 公式 | 规则 |
|---|---|---|---|---|---|
| IRI | 支持 | 支持 | 支持 | 支持 | 支持 |
| Blank Node | 支持 | 不支持 | 支持 | 支持 | 支持 |
| Literal | 一般不支持 | 不支持 | 支持 | 支持 | 支持 |
| TripleTerm (RDF 1.2) | 支持 | 不支持 | 支持 | 支持 | 支持 |
| Variable | 不支持 | 支持（规则） | 不支持 | 支持 | 支持 |
| Collection | 支持 | 不支持 | 支持 | 支持 | 支持 |
| BNodeProp | 支持 | 不支持 | 支持 | 支持 | 支持 |

## 3. N3 特有语义项

| 特性 | 说明 |
|---|---|
| Formula | `{ ... }`，不直接断言为真，适用于规则前提/结论 |
| Rule | `{ ... } => { ... }` |
| Builtins | `math:`, `log:`, `string:` 等 |
| Resource Path | `!`, `^` 用于宾/主位路径 |
