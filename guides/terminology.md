# 术语对照：代码注释里的"黑话"→ 大白话

> 指南：[索引](README.md) ｜ 术语对照（本页）

**为什么有这一页**：本项目的代码注释里会写 `役 35` · `钉 8` · `台账` · `口径` · `门况` 这类**工程简称**
（在本仓正文里它们是**正式名**，不是俚语；对外部读者才是"黑话"）。这一页把它们译成一句话，
让你读注释/提交信息/CI 报错时不用回头猜。

**边界（三条，先看清）**

1. **本页是释义页，不是命名源**——`黑话` 列是正式名；右列的解释**只许用来解释**，
   **不得**在代码、文档、API 里当别名替代正式名（防"一义两词"）。
2. **定义权在主仓世界卷**：本页是主仓 `bangto/world/jargon-map.spec.md`（**v1.3**）的**摘录**，
   只收"代码注释里最常撞到读者"的条目；释义与口径**以该卷为准**。
   （子仓与发布包看不到 `bangto/`，所以要在这里自列一份。）
3. **不追求全量**：世界卷有 138 条，本页只摘常用的；没收录的词见"3 节"的指路。

## 1. 治理与账（最常撞见）

| 黑话 | 一句话 | 代码注释里通常意味什么 |
|---|---|---|
| **役 / 笔 / 步** | 阶段 / 批次 / 步骤 | `役`=一个战役阶段；`笔`=一次原子改动；`步`=验收序列里的一步（注释里说"本笔只管 X"= 这次改动只做 X） |
| **台账** | 逐条在册的表 | 把事实/点位**逐条登记可核对**的表（"入台账"= 记进这种表） |
| **收账** | 结算这一笔 | 一笔改动做完后，把状态、数字、证据**落回账上**（不是"提交代码"） |
| **收官** | 这一役收口 | 阶段完成：前置齐 + 门绿 + 账落（不是"代码写完"） |
| **回灌①** | 把结论写回上位卷 | 模块级结论升格进世界卷（**文档动作**） |
| **回灌②** | 合成事件回喂 | 引擎把剥离/合成的词法事件**再喂回**状态机（**机制动作**；与①同名不同义） |

## 2. 门与真伪（读 CI 报错必备）

| 黑话 | 一句话 | 代码注释里通常意味什么 |
|---|---|---|
| **门** | 可执行检查 | 能**自动判红/绿**的判据（测试、CI 步骤、断言）——"文档里写了"不算门 |
| **钉子 / 钉** | 钉死的断言 | 把某条事实/期望**固定成断言**，改动即红（"钉 8"= 第 8 条这种钉子） |
| **口径** | 判定标准 | 规定"什么算一致/算够"的标准（"同口径"= 两端按同一标准比） |
| **门况** | 报数那一行 | 收账时固定报告各门用例数与覆盖率的那行（如 `子仓 507/507`） |
| **黄金门 / 逐字节** | 金样对拍 | 钉住时间戳再生 **≡ 入库产物逐字节** + 强幂等（生成物不得手改） |
| **棘轮** | 只进不退的门 | 数值门**单向性**：大者只许不降、小者只许不增（不是"目标值"） |

## 3. 世界卷没立条目、但注释里也会遇到（**非定义**，只给指路）

这些词有**入库的正式事实源**，正式语境请按指向查看；下表只帮你"读懂注释"：

| 词 | 意思 | 正式源（入库） |
|---|---|---|
| **复核面 / 面一 · 面二 · 面三 · 面四** | "读数面"：套件自报行 / 产物与 IR / 覆盖率 / 性能 四张**可复现读数表** | `review.md` §1.1·§1.2 与四张 `*-review.txt` |
| **裁定 / 拍** | 决策被**定下来**（谁拍的、拍成什么） | `adr.md`（决策全文）+ `release-checklist.md`（发版口径） |
| **沿革** | 这一条**怎么演变到今天**的（历史） | 各卷的"沿革"行 + `CHANGELOG.md`（对外） |
| **冻结** | **禁止改动**（如上游语料的字节、某字段的语义） | 语境就地说明（例：`.rdf-tests/README.md` 的字节冻结） |
| **坑 / 坑册** | 踩过的**教训**，防再犯 | `ctx.md`（**活账，不入库** ⇒ 注释里常直接写一句结论） |
| **红 / 绿** | 门**失败 / 通过** | CI 与本地 `ci/*.sh` 输出 |

## 4. 维护条件与重评估（这一页怎么活下去）

**维护条件（谁改、什么时候改）**

1. **只做摘录**：条目**只在**主仓世界卷 `bangto/world/jargon-map.spec.md` 变更时同步；
   本页**不自主新增命名、不改写定义**（新增须先在世界卷立）。
2. **声明显式**：同步时必须同笔更新本页顶部的**世界卷版本号**（现为 v1.3）与 `CHANGELOG.md`（若影响对外）。
3. **结构门**：本页受 `ci/docs-check.sh` 管（H1 / 导航行 / 零死链 / 命名 / 被索引），并随
   `sh ci/release-check.sh` 在**发版前**必过。

**重评估条件（满足任一 ⇒ 重新决定本页形态）**

1. **施工账淡出代码注释** ⇒ 本页**可退役**（改为在 `adr`/`spec` 里自然解释；参见主仓那条分层收窄路线）。
2. **黑话升格进公开 API / `.mbti`** ⇒ 转为**正式术语表**（走词表流程），本页降为指针。
3. **摘录与世界卷出现分歧** ⇒ **以世界卷为准**并同笔修本页（不得两处各说一套）。
4. **子仓/发布包能直接看到世界卷**（如主仓公开或镜像）⇒ 本页降级为**指针页**。
