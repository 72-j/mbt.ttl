# gen_n3v2 宪法（const）

版本：v1.0.0（2026-09-20 立卷；红线自 `spec.md` §3 不变量（I-1..I-9）与 §5.1 权威破例归位清单提炼，
正文事实仍在 `spec.md`，本卷只收**绝对不允许 / 必须**的那几条）

**效力与时效**（`bangto/world/const.md` §5.1/§5.2）：本卷是**红线条款**——**冻结，只减不增**；
改一条**必须**由用户裁决并以 `adr.md` 条目留痕；**只对 `src/ttl/src/gen_n3v2/` 有效**。
术语以 `bangto/world/vocabulary.spec.md`（v2.3）为准：契约成员 = `Actions` / `EffectHandler` / `Supervisor`
（`LoopPolicy` 为废弃别名、正名 `Supervisor`；本包代码自 ADR-33/役34 起为 **`N3Supervisor`**）；
手写层称 **`Assembly`（装配层）**，不称 `User`（`spec.md` §1 的分层名同此口径）。

## 1 表源唯一事实源（必须 / 禁止）

1. **表源唯一**：`(state, event) → action` 的映射**只**由表源（`n3v2_base.toml` + `n3v2_trans.toml`）
   定义；引擎不得用条件分支**复制**表的决策。
2. **生成物禁手编**：`n3.mbt` 是生成物——**禁止**手改；任何改动**必须**走"表源/模板 → 再生 → 对拍"。
3. **同笔再生**：表源或生成模板一变，**必须**同笔再生并让 **G9 字节对拍**保持绿（`src/rdf/n3gen`）。

## 2 状态与破例可数（必须 / 禁止）

4. **`ctx.state` 直写只允许一个机制位**：即 `pop_bnode_prop` 兑现帧携带的 `ret_state`
   （`spec.md` §5.1 [R-03-1]）；**禁止**在 action 里新增 `ctx.state` 直写。
5. **链形异判破例恒可数**：`[R-03-2]`（`path_end_nested` 反跳拒）/ `[R-03-3]`（`path_subj_end` 动词位链）
   两条破例**必须**在 `spec.md` §5.1 在册，且每条注明"**为何表内表达不了**"。
6. **新增破例先入册**：任何新破例**必须**先登记 `spec.md` §5.1（该清单**条目只减不增**），
   并同步 `adr.md`；**禁止**先改代码后补账。

## 3 判据锚引擎真件（必须 / 禁止）

7. **值级对拍锚引擎**：数据面（表/配置）与模型面**必须各自**设门，且**每道门都锚引擎真件**
   （真探针读数 + 真金样）；**禁止**以声明互证、**禁止**手抄（`bangto/world/const.md` §6.4.4）。
8. **不可比必须逐项入册**：门对暂不可判的项**必须**逐项入册（理由 + 按类计数钉死）；
   **禁止**整行跳过（§6.4.2）。

## 4 生成物与写盘（必须 / 禁止）

9. **写盘原子化**：写生成物**必须**"临时文件 + 原子改名"；**禁止** truncate-then-write
   （`bangto/world/const.md` §6.4.6）。
10. **生成物只可重生成**：快照/复核表/金样类生成物**必须**标 `DO NOT EDIT MANUALLY` 并只经重生成更新；
    **禁止**手工编辑（含"对齐一下表格"）。

## 5 交付门（必须）

11. **静态零告警**：`moon check --deny-warn` 必须为 0。
12. **测试与套件**：`moon test src/gen_n3v2` 必须全绿；套件（N3Tests / rdf-turtle / rdf12-turtle）
    失败数必须为 0（自报行入 `../suite-review.txt` 复核表）。
13. **棘轮不降**：行覆盖率与可达命令名覆盖率**必须**不低于基线文件（`coverage-baseline.txt` /
    `reachable-coverage-baseline.txt`；数字**只引用**，禁复写）。
14. **复核面可复现**：本包相关面的复核表**必须**能被第三方按表头命令重跑出逐字节同表
    （`bangto/world/const.md` §6.5）。
